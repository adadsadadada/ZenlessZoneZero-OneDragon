# 最低成本养成计划

## 先说结论

**60级一队暂时不重练。先把二队变成可用队伍，材料优先投给40级艾莲。** 养成资源数量、音擎、影画未提供，因此这里只列顺序，不虚构材料消耗或具体伤害提升百分比。

| 优先级 | 角色 | 当前 | 动作 | 停手/验收条件 |
|---:|---|---:|---|---|
| P0 | 星见雅/南宫羽/浮波柚叶 | 全60 | 保留现有成型队；仅核对驱动盘主词条、技能顺序 | 先打一轮目标关卡作基线 |
| P1 | 艾莲 | 40 | 根据现有材料、音擎逐步升等级与主输出技能 | 能独立完成目标二队输出循环 |
| P2 | 安比 | 40 | 作为低成本击破位先满足实战需求 | 能按预期触发失衡 |
| P2 | 苍角 | 40 | 保证核心辅助增益、顺畅切艾莲 | 增益覆盖和切人顺序可复现 |
| P3 | 照 | 50 | 不急重练；作为第二队替换方案实测 | 只有明确快于原队才继续投入 |
| 暂缓 | 卢西娅 / 狛野真斗 / 潘引壶 | 均1 | 先不组全新命破队 | 二队达标后再启动 |
| 暂缓 | 其余1-30级角色 | 1-30 | 不为凑队随意分散材料 | 新关卡有明确需求时再练 |

## 新投入前的检查

- [ ] 确认目标关卡与奖杯/星级要求
- [ ] 截图二队当前等级、武器与驱动盘
- [ ] 看角色专属与替代音擎，优先盘活现有装备
- [ ] 先尝试低投入版本，再决定是否升至60级
- [ ] 新抽卡是否比已有角色升级带来更明显的改善？

**不是所有角色都必须60级。** 是否提升击破/支援等级取决于该角色机制与关卡难度，不能照着主C强度一视同仁。
