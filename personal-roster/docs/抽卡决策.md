# 抽卡决策原则（高性价比优先）

## 当前立场

**能用现有角色解决，就先不买新问题。** 本账号已有60级雅/南宫羽/柚叶，第二队的主要短板是艾莲练度与击破/辅助组合尚未验证；不等于必须追加新主C。

### 新角色是否值得抽：四个条件

1. **填真正空缺**：优先补二队缺口，而非重复一队现成职位。
2. **能共用既有投资**：无需再拉起2名1级限定队友的优先。
3. **收益有来源**：角色机制来源+至少一种稳定攻略评价，不能依据立绘、PV、倍率传言。
4. **保底足够**：菲林、票数、大小保底、目标复刻时间未知，不能判定“值得砸多少抽”。

### 默认动作

- 不主动抽额外新主C，只为满足二队投入回报。
- 对**通用型击破/辅助**保持关注；是否适配艾莲，需查被动条件和实测。
- 限时池到期前再复核官方规则，防止计划过时。
- 绝不把一名角色“理论可搭”写成“必须抽”。

### 禁止复发的误判

- 不得因为误把南宫羽当耀嘉音，就推荐“补某某角色”来修补不存在的队伍。
- 不得假设拥有薇薇安、莱卡恩、莱特。
- 不得将角色名称、池期或机制以未经验证的单条社区帖当做官方事实。
